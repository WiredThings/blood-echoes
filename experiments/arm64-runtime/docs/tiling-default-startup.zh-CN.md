# 十四类平铺库默认首启准备（仅隔离 ARM64 版）

十四类完整 Metal 源码库已接入隔离版的原 final-exec 默认准备入口。正式应用、正式存档、设置、原缓存和 GitHub Release 未变。配套 QA 包在本机 artifacts/arm64-qa-20261026-fourteen-libraries；它依赖现有 Shared 开发树，不是可移植安装器，也不分发用户本机 Metal 编译产物。

## 实现与边界

沿原 `TilingShader`、`TextureTilingSource`、`CompileOptions` 和真实 typed entry factory 收集全部十四种有限源码身份：8/16/32/64/96/128 位各两种布局，加上32/64位纹理转换。原热 map、32项纹理转换缓存预算、像素算法和画质保持原样。准备进程逐项释放临时库和函数，不创建纹理、guest 地址表或游戏 renderer owner。

八类固定最终 PSO 与十四类库分别报告完成状态；十四份库不代表全部最终函数常量组合，更不等于全游戏 PSO。内部 fixed helper 协议升级到2，library 子记录为1；旧schema1和usage64组件明确不可用，不伪装成新协议。跨进程游戏协议和退出码未改。

原库收集有十秒预算。本轮补齐控制器的有界增量处理：后续发现的新请求沿同一 builder 补建，分别跟踪固定PSO和库的进展；八类PSO先完成也不能提前宣告十四库完成。无进展或超预算返回deferred。完整暖探测通过后跳过该部分builder。

## 正确性与失败控制

- 21项候选合同与兼容控制通过；现有控制器、响应、子进程、含空格dyld路径和打包回归已按schema2更新。包含晚请求、库无进展、取消和观察失败控制。
- 原生反例逐类覆盖缺库、有效库缺main0、坏摘要、库内容损坏，共56项，加正常对照1项。每个反例只在新克隆中损坏一个目标：该项成功回Source，其余13项Local；八类固定PSO均strict命中、普通PSO编译0，不谎报整体完成。
- 缺入口反例使用项目自写的有效metallib，并同步更新收据长度与摘要，确保真正到达原typed entry校验，不是只测文件损坏。没有放宽生产加载器的目录、身份、摘要或入口检查。
- 此前9进程像素控制已经证明Local路径：36个普通纹理、4个代理输出对照完全一致，原CPU参考与guard也通过；故意错误根目录仍拒绝并Source回退。详[像素摘要](../evidence/tiling-local-pixel-validation-20261026/summary.json)与[反例摘要](../evidence/tiling-library-negatives-20261026/summary.json)。
- 已有230GPU单元的冻结同源库复用前全部散列核验；新增配套30CPU单元、两个AvPlayer桥和GPU窗口main。12份native layout依赖逐个匹配；包中真实能力查询为2、运行中的GPU路径与SHA均核验。压缩包854项，无游戏文件、存档或本机AIR/metallib/archive输出。
