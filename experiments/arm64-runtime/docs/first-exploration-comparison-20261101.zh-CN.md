# 首次探索／转镜头对照：有限结果与无效范围

## 固定条件

69cb146e 来源隔离包，FEX、原 Metal／内存／速度图／两级页表等选项保持。正常源脚本、正式应用和原缓存不修改。原 Swift QA 条件冻结并校验实际 CPU/GPU 与脚本身份，新建测试存档、数据和独立 APFS 缓存克隆；每组恢复相同起点与缓存种子，原文件全部保留。静音、离线、快速存档关闭，只用原输入接口；性能轮次无 Cua、截图、录屏及重型诊断。

比较的是既有 `BB_MTL_LOCAL_AOT_MODE=off` 与 `auto` 的**整套 Metal 自动准备／采用流程**，不是单独新增 15 条静态派生的边际收益。该选项会改变本机库使用及相应归档身份，不能表述为只改变一个管线文件。A→B 单对顺序、系统驱动缓存未清除，存在顺序影响。

## 路线与录制

用户在独立录制窗口完成 Fn+F9：620 个状态变化、91.861 秒，最终全部松开。使用现有 runtime_pad 格式，没有另做输入系统。

标准 `--benchmark` 正确拒绝物理输入模式；录制使用单独的、逐字核对来源的私有入口，只将工作目录绑定实际准入包，并将脚本输入限定替换成**精确私有 data/user/cache/pad/record/nonce + 离线／静音／快速存档关闭**校验。包内脚本不变，回放轮次仍用原自动入口。录制轮次不是性能对照。

记录前有约 34 秒静止，34.669–62.154 秒为转镜头前缀，62.154 秒后开始行走。回放每轮从相同存档重新载入，只在实际场景出现后触发；不沿用上轮角色终点。

完整路线的 A/B 最大水平偏差 2.64，超过 1.5；与手动录制轨迹的最大水平差分别约 35.95 / 35.93，垂直约 2.68 / 2.67。**没有放宽门槛，完整新区域对照无效**。所有原始帧及长帧仍保留，缺少相机信息不用于删去大帧。
